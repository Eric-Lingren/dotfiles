How to read this page
  • Target case: a case that failed the check being fixed. The fix is judged on these.
  • Sentinel case: a case that passed every check. It must keep passing, so a fix cannot break something else.
  • Passed twice: a target must pass on two separate runs, so one lucky run does not count.
  • pp: percentage points. 40% to 60% is +20 pp.
  • n/a: no case applied (for example a check that only runs on rejected verdicts).
