## Writing new browser-checker.md

Rewrote to:
1. Accept spec/base_url/base_server_url/repo/run_dir/base_sha as inputs
2. Determine verify_host from repo-policy.json; return skipped if not "local"
3. For non-anonymous role: call browser-auth.py ensure; on exit 1 return skipped:auth_expired
4. Compute spec hash (SHA256 of canonical JSON)
5. For each viewport: try baseline-cache.py get; on any miss run browser-verify.mjs against base_server_url; put all viewports in cache; copy baselines to run_dir/baselines/
6. Run browser-verify.mjs against base_url (Candidate) with --baseline-dir
7. Read and return result.json from browser-verify.mjs
8. No check.mjs generated under any circumstance
