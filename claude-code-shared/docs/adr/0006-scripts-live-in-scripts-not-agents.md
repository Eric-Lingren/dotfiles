# Scripts live in `scripts/`, not `agents/`

Agents are grouped by lane under `agents/<group>/<name>.md` (`build`, `investigate`, `seed-review`, `egress`, `learning`, `shared`, `skill-agents`). Companion shell scripts that used to sit next to wrapped agents now live in `scripts/egress/`. The `agents/` tree holds only `.md` files plus the generated `README.md` index.

## Consequences

- The global CLAUDE.md rule (scripts live in `claude-code-shared/scripts/`) wins over co-location with the owning agent.
- [ADR-0002](0002-agent-subdir-iff-companion-files.md) ("subdirectory iff companion files") is superseded; its file stays in place for history.
- `validate-registry.py` recurses through `agents/` groups; `agents/README.md` is generated by `scripts/registration/gen-agents-readme.py`.
