# T-0081 — Wire investigator into pr-code-review as pre-submit claim gate

**Start:** 2026-08-14

## Task

Wire investigator into `pr-code-review` as a pre-submit claim gate. Before any finding is posted to the PR, `pr-code-review` spawns investigator on each factual claim in the finding body. Claims returning `VERIFIED_FALSE` are dropped. `INSUFFICIENT_EVIDENCE` claims are downgraded with an explicit caveat. `VERIFIED_TRUE` and `CONTESTED` proceed to posting.

## Acceptance criteria

- [ ] pr-code-review spawns investigator for pre-submit claim verification before posting
- [ ] A VERIFIED_FALSE claim in a finding body is dropped before posting
- [ ] An INSUFFICIENT_EVIDENCE claim is downgraded or dropped, not stated as fact
- [ ] Test or fixture verifies gate behavior
