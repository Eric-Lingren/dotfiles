# T-0074 — Add --claude flag to auto-start agent in worktree

**Start:** 2026-08-15

## Task

Extend `wt <branch> [base] [--claude]` so that when `--claude` is passed, the zsh function launches the `claude` CLI in the worktree directory after the cd completes.

## Acceptance Criteria

- [ ] Tests confirm --claude flag is parsed correctly in engine
- [ ] Tests confirm plain wt does not auto-launch claude
- [ ] Flag works whether placed before or after the branch name
- [ ] `wt feat/x develop --claude` (with base override) also works

---

## Execution Trace

### Baseline

Confirmed 63 tests passing before changes.

### Engine changes (.scripts/worktree)

1. Added position-independent `--claude` flag stripping at the top of the script (loops over all args, rebuilds the positional array without `--claude`, sets `LAUNCH_CLAUDE=true` if found).
2. Added `emit_path()` helper that prints `LAUNCH_CLAUDE\n<path>` when the flag is set, or just `<path>` otherwise.
3. Replaced all four `echo "$WORKTREE_DIR"` exit points (cases 1-4) with `emit_path "$WORKTREE_DIR"`.
4. Updated help text to document `[--claude]` option.

### Zsh wrapper changes (.zshrc)

Updated `wt` function to:
- Capture full engine stdout into `$output`
- Read first line; if it equals `LAUNCH_CLAUDE`, set `launch_claude=true` and take the path from the second line
- Otherwise treat the single line as the path
- After `cd`, exec `claude` if `launch_claude` is true

### Tests (.scripts/tests/test-worktree.sh)

Added 21 new tests covering:
- Plain `wt` produces no `LAUNCH_CLAUDE` in stdout
- `--claude` after branch name (case1 existing worktree)
- `--claude` before branch name (position-independent)
- `wt feat/x develop --claude` (base override + flag)
- `--claude` with case2 (local branch)
- `--claude` with case3 (remote branch)
- `.zshrc` wt function contains `LAUNCH_CLAUDE` handling and `claude` invocation
