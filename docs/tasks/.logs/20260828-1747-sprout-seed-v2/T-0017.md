## Step 2 — Review gxpush _matches_exclude logic

File: `.scripts/gxpush`, lines 55-64

```bash
_matches_exclude() {
  local f="$1"
  while IFS= read -r pat; do
    [[ -z "$pat" ]] && continue
    if [[ "$f" == "$pat"* || "$f" == *"/$pat"* ]]; then
      return 0
    fi
  done <<< "$GX_EXCLUDE_PATS"
  return 1
}
```

Problem: `"$pat"` is quoted on the right side of `==` in `[[ ]]`, so wildcards inside `$pat` are treated as LITERALS, not globs. Pattern `docs/tasks/*-revisions-r*.json` would NOT match `docs/tasks/20260828-revisions-r1.json`.

Fix: Add a `case "$f" in $pat)` branch (unquoted `$pat`) to enable glob pattern matching for entries that contain `*`.
