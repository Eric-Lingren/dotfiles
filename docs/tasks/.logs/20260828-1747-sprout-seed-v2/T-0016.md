# T-0016 — Set gxpush draft PR default

**Start:** 2026-08-28

## Task
Change `GX_PR_DRAFT` default from `false` to `true` in gxpush script.

## Analysis

Inspected `.scripts/gxpush` line 342:

```bash
if [[ "${GX_PR_DRAFT:-false}" == "true" ]]; then
```

The default is `false`, so PRs are created as non-draft unless `GX_PR_DRAFT=true` is set.

**Required change:** Change `:-false` to `:-true` so that:
- Without `GX_PR_DRAFT` set → draft PR (default behavior)
- With `GX_PR_DRAFT=false` → non-draft PR
- With `GX_PR_DRAFT=true` → draft PR (explicitly set)

## Change

Modified `.scripts/gxpush` line 342:
- Before: `if [[ "${GX_PR_DRAFT:-false}" == "true" ]]; then`
- After:  `if [[ "${GX_PR_DRAFT:-true}" == "true" ]]; then`

Also updated the echo message on line 343 to be accurate.

## Verification

- `GX_PR_DRAFT=false` → evaluates to `"false"` → condition is false → `gh pr create` (no --draft) called ✓
- `GX_PR_DRAFT=true` → evaluates to `"true"` → condition is true → `gh pr create --draft` called ✓
